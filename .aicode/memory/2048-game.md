- `public.scores` 是表（有 `difficulty` 字段）
- `api.scores` 是视图（无 `difficulty` 字段）
- REST 接口默认走 `api` schema，所以客户端必须显式加 `Accept-Profile: public` 和 `Content-Profile: public`
- 当前代码已经用 `SUPA_H` 统一携带这两个头

## 难度功能（v15 已实现）
- 登录后弹出难度选择（简单 5×5 / 普通 4×4 / 困难 3×3）
- `const SIZE = 4` 改为 `let SIZE`，通过 `documentElement.style.setProperty('--n', SIZE)` 动态计算 cell 尺寸
- 棋盘格子重建在 `buildGrid()` 里，`newGame()` 每次调用
- `move()` 遍历顺序用 `Array.from({length: SIZE})` 动态生成，不再写死 `[0,1,2,3]`
- 排行榜分页签（简单/普通/困难），页签默认高亮当前难度
- 上传带 `difficulty` 字段；字段缺失时降级走兼容模式（已去掉降级，现在直接用 public profile）
